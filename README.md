Shell, I/O Redirection and Filters

Description

This project focuses on understanding and applying fundamental I/O redirection techniques, pipeline concepts, and essential command-line filters in the Bash shell under Ubuntu 20.04 LTS.

Concepts & Topics Covered

Standard Streams: Understanding stdin (0), stdout (1), and stderr (2).

I/O Redirections:

Redirecting standard output using > (overwrite) and >> (append).

Redirecting standard error using 2> or merging error output to standard output using 2>&1.

Pipes: Connecting the output of one command to the input of another using |.

Shell Filters & Utilities:

echo: Printing text to standard output.

cat: Displaying and concatenating file contents.

head / tail: Outputting the first or last parts of files.

find: Searching for files and directories.

wc: Counting lines, words, and characters/bytes.

sort / uniq: Sorting lines and filtering duplicate entries.

grep: Searching for patterns in text files.

tr: Translating, squeezing, or deleting characters.

rev: Reversing characters per line.

cut: Extracting specific sections from lines of text.

Requirements & Constraints

OS Environment: Ubuntu 20.04 LTS

Script Specifications:

All scripts must start with #!/bin/bash.

All scripts must be executable (chmod +x <script_name>).

All files should end with a new line.

Scripts must strictly conform to project-specific line limitations.
