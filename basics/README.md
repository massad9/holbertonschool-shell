# Shell Basics — Scripts

## Description

This directory contains Bash scripts for learning basic Linux shell commands and filesystem navigation.

## Scripts

### 0-current_working_directory

This script displays the absolute path of the current working directory.

## Requirements

- Scripts are tested on Ubuntu 22.04 LTS.
- Every script must contain exactly two lines.
- The first line must be `#!/bin/bash`.
- Scripts must be executable.
- Every file must end with a newline.
- Allowed editors: vi, vim, and Emacs.
- Backticks, `&&`, `||`, and `;` are not allowed in scripts.
